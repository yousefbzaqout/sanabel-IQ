## [1.0.0] - 2026-09-19

### Added

- Interactive lesson engine (six stations) with Filament admin and student Livewire runners
- Immersive quiz runner, celebration screen, learning map, Sonbol mascot, and audio narration
- Child PIN login and adults-portal switch for safe household auth
- Multi-tenant B2B foundation (tenants, isolation middleware, demo-request conversion)
- Parent Filament cockpit with mastery analytics, goals, materials, and marketing-ready widgets
- Teacher portal surfaces and admin resources for lessons, students, users, and demo requests
- Adaptive mastery / mascot AI feedback services and lesson analytics pipeline
- Grade 1 Palestinian curriculum seeders and interactive lesson prototypes (Arabic, Math, Islamic, Civics)
- Marketing feature mockups (`docs/marketing/feature-mockups/`)
- Professional repository docs: README, HOW_IT_WORKS, SKILLS, CONTRIBUTING, SECURITY

### Changed

- Student shells standardized for Arabic RTL and mobile ergonomics
- Session serialization-aware tooling for celebration priming and demos

### Security

- Documented vulnerability reporting in SECURITY.md
- Reinforced tenant scoping expectations for student and analytics data
